# Technology Stack

**Analysis Date:** 2026-10-14

## Languages

**Primary:**
- Python 3.12 (`requires-python = ">=3.12"` in `pyproject.toml`; pinned in `.python-version`) - all application code under `src/lecture_study/`, operational scripts under `scripts/`, and tests under `tests/`

**Secondary:**
- Bash - native engine provisioning in `scripts/01_provision_engines.sh`, git hooks in `.githooks/`, container entrypoint in `infra/docker-entrypoint.sh`
- YAML - catalog configuration shape documented in `config/targets.example.yaml`; CI in `.github/workflows/ci.yml`
- Typst - document typesetting markup generated by `src/lecture_study/study_materials/academic_typst.py` and invoked as an external binary
- Markdown - study-guide source and published output (`src/lecture_study/publishing/markdown_compiler.py`, `src/lecture_study/site/renderer.py`)

## Runtime

**Environment:**
- CPython 3.12 on macOS (Apple Silicon). The native stages depend on Apple frameworks (Vision, Quartz via pyobjc) and MLX, so macOS is the only supported host for the full pipeline (`.github/workflows/ci.yml` runs the `test` job on `macos-15`).
- Container runtime for the study site only: `python:3.12-slim` (`Dockerfile.site`). The container does not include the pipeline's native or ML dependencies.

**Package Manager:**
- uv (Astral). Commands in `Makefile` use `uv run`; CI uses `uv sync --group dev --locked`.
- Lockfile: present (`uv.lock`)
- Build backend: hatchling (`[build-system]` in `pyproject.toml`); wheel packages `src/lecture_study`.

## Frameworks

**Core:**
- FastAPI 0.139.2 - HTTP application for the study site, `src/lecture_study/site/app.py` (the ASGI app `lecture_study.site.app:app`)
- Starlette (transitive via FastAPI) - `StaticFiles` mounts and middleware in `src/lecture_study/site/app.py`; `run_in_threadpool` for blocking work
- Uvicorn 0.51.0 - ASGI server; started by `make site` and by `infra/docker-entrypoint.sh` in serve mode
- Pydantic 2.13.4 - domain and schema models, e.g. `src/lecture_study/domain/models.py` (`MockExam`, `MockQuestion`, `SafeIdentifier`)
- Jinja2 3.1.6 - HTML templating dependency (declared in `pyproject.toml`)
- markdown-it-py 4.2.0 - Markdown-to-HTML pre-rendering for the site (`src/lecture_study/site/generator.py`)
- MLX Audio 0.5.4 (`mlx-audio`) with MLX 0.32.2 - local text-to-speech for podcast audio; invoked as `python -m mlx_audio.tts.generate` from `src/lecture_study/tts/generator.py`. Engine: Kokoro-82M (see `docs/decisions/0032-kokoro-mlx-podcast-tts-engine.md`)
- misaki 0.9.4 and espeakng-loader 0.2.4 / phonemizer-fork 3.3.2 - phonemization support for the TTS engine (declared dependencies)
- pyobjc-framework-Quartz 12.2.1 and pyobjc-framework-Vision 12.2.1 (darwin only) - native OCR through Apple Vision in `src/lecture_study/extraction/ocr_worker.py`

**Testing:**
- pytest 9.1.1 with pytest-asyncio 1.4.0 and pytest-cov 7.1.0 - configured in `[tool.pytest.ini_options]` (`testpaths = ["tests"]`) in `pyproject.toml`
- httpx 0.28.1 (dev group) - test client support for the FastAPI app

**Build/Dev:**
- ruff 0.15.22 - linting and formatting (`uv run ruff check .`, `uv run ruff format --check .`)
- mypy 2.3.0 in strict mode (`[tool.mypy] strict = true`, `uv run mypy src`)
- hatchling - build backend
- GNU Make - task entrypoints in `Makefile` (`test`, `lint`, `run`, `site`, `clean`, `hooks`)
- Git hooks - versioned in `.githooks/` (`pre-commit`, `commit-msg`, `pre-merge-commit`, `pre-push`), installed by `make hooks`

## Key Dependencies

- `pyyaml` 6.0.3 - loads catalog and target configuration (`config/targets.local.yaml`, shape in `config/targets.example.yaml`)
- `aiofiles` 25.1.0 - declared for asynchronous file I/O

**Infrastructure:**
- `rich` 15.0.0 - console output for the CLI (`src/lecture_study/cli/`)
- `markdown-it-py` 4.2.0 - Markdown rendering shared by publishing and site generation
- Standard library heavily used in place of third-party packages: `sqlite3` (quality stores under `src/lecture_study/quality/*_sqlite.py`), `hashlib`/`hmac` (signing and certificates), `fcntl` (file locking), `asyncio` subprocess APIs (`src/lecture_study/ops/process_lifecycle.py`)

## External Binaries and Native Engines

Not Python packages. Resolved by path or on `PATH`; see `src/lecture_study/ops/process_environment.py` (`resolve_trusted_executable`) and `scripts/01_provision_engines.sh`.

- `ffmpeg` and `ffprobe` - media extraction, frame sampling, audio assembly (`src/lecture_study/extraction/media_workers.py`, `src/lecture_study/tts/generator.py`); installed via Homebrew
- `typst` - PDF typesetting for study materials (`src/lecture_study/study_materials/academic_typst.py`); installed via Homebrew
- `whisper-cli` from whisper.cpp - speech-to-text, binary at `engines/whisper.cpp/build/bin/whisper-cli` (`src/lecture_study/transcription/whisper_worker.py`); model `ggml-large-v3-turbo.bin`
- `llama-mtmd-cli` from llama.cpp - vision captioning of slide figures, binary at `engines/llama.cpp/build/bin/llama-mtmd-cli` (`src/lecture_study/captioning/vlm_worker.py`)
- `codex` CLI - the LLM route for semantic extraction, drafting, critic review, flashcards, mock exams, and podcast scripts; invoked by the `scripts/generate_codex_*.py` scripts, which the orchestrator in `src/lecture_study/cli/orchestrator.py` runs as child processes. - `say` (macOS) - referenced by historical stages and retained in the environment allowlist; superseded for podcast audio by MLX Audio (ADR 0032)
- `gitleaks` - secret scanning in CI and locally (`.github/workflows/ci.yml`)
- `huggingface-cli` - model download helper installed by `scripts/01_provision_engines.sh`

**Pinned native sources** (`scripts/01_provision_engines.sh`):
- whisper.cpp at commit `080bbbe85230f624f0b52127f1ae1218247989f9`
- llama.cpp at commit `91d2fc387529940230555abd297a8b5e99737d3f`
- Whisper model `ggml-large-v3-turbo.bin`, verified by SHA-256 at provisioning time

## Configuration

**Environment:**
- Configuration is read from the process environment first, then from a `.env` file in the working directory (only for `LECTURE_STUDY_QUALITY_HMAC_KEY_B64`, via `python-dotenv` in `src/lecture_study/quality/trust.py`). A `.env` file is never read by the site container.
- Template of expected variables: `.env.example`. Variable names only are documented here; values are never recorded in this repository.
- Environment variables consumed by the code:
  - `LECTURE_STUDY_QUALITY_HMAC_KEY_B64` - base64 HMAC key that signs quality-gate certificates (ADR 0026)
  - `LECTURE_STUDY_QUALITY_SIGNING_KEY` - signing key reference in the quality package
  - `LECTURE_STUDY_SITE_CREDENTIALS` - path to the site credentials file (default `config/site-credentials.txt`), `src/lecture_study/site/access.py`
  - `LECTURE_STUDY_SITE_SESSION_KEY` - path to the session signing key (default `config/session-key/site-session-key`), `src/lecture_study/site/sessions.py`
  - `LECTURE_STUDY_SITE_MOCK_EXAMS` - mock-exam directory (default `workspace/data/14_mock_exams`)
  - `LECTURE_STUDY_SITE_ACADEMIC_SCHEDULE` - academic schedule input for the site
  - `LECTURE_STUDY_PUBLIC_SETTING` - public-publication setting (ADR 0042/0044)
  - `LECTURE_STUDY_DENYLIST` - path to the private denylist used by `scripts/denylist_scan.py` and the git hooks; kept outside the repository
  - `HOME` - read to locate `~/.codex` for the Codex CLI child processes
- Environment passed to child processes is restricted by an allowlist in `src/lecture_study/ops/process_environment.py` (includes `PATH`, `HOME`, and the `TEMP`/`TMPDIR` family, and the `LECTURE_STUDY_QUALITY_` prefix)
- Runtime data is confined under `workspace/` (git-ignored), per `.gitignore`

**Build:**
- `pyproject.toml` - project metadata, dependencies, dependency groups, tool configuration (pytest, mypy)
- `uv.lock` - resolved dependency graph
- `Dockerfile.site` - narrow site image; installs pinned `fastapi==0.139.2 uvicorn==0.51.0 pyyaml==6.0.3 markdown-it-py==4.2.0 pydantic==2.13.4` with pip, runs as uid/gid 10001
- `.dockerignore` - build context exclusions
- `Makefile` - `WHISPER_MODEL_PATH` default `engines/whisper.cpp/models/ggml-large-v3-turbo.bin`
- `.python-version` - `3.12`
- `.gitignore` - excludes `engines/`, `workspace/`, `.venv`, caches, and local catalog files

## Platform Requirements

**Development:**
- macOS on Apple Silicon (Metal API used by whisper.cpp and llama.cpp builds; Apple Vision and MLX require macOS)
- Python 3.12 managed by uv
- Homebrew packages: `ffmpeg`, `typst`, `poppler`, `gitleaks`, plus `huggingface-cli` (provisioned by `scripts/01_provision_engines.sh`; CI installs `ffmpeg typst poppler gitleaks`)
- Native engines built under `engines/` by `scripts/01_provision_engines.sh` (git-ignored)
- The `codex` CLI installed and authenticated under the user's account

**Production:**
- Study site: Docker image built from `Dockerfile.site` (`python:3.12-slim`), served by Uvicorn on port 8000 with the logging configuration in `infra/uvicorn-logging.json`. Corpus and video library are mounted as volumes, not baked into the image (ADR 0029).
- Full pipeline: runs locally on macOS (no hosted deployment is defined in the repository)
