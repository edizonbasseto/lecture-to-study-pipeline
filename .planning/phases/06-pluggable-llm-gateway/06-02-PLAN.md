## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pipeline to llama.cpp child | Prompt file and argv cross into a local native binary |
| configuration to argv | Operator-configured model path becomes a `-m` argument |
| ambient environment to child | Inherited variables could re-enable downloads |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-06 | Information disclosure | Silent download or outbound request by llama.cpp | high | mitigate | `--offline` plus `LLAMA_ARG_OFFLINE=1`; env built from the sanitized allowlist with every other `LLAMA_ARG_*` and `HF_*` removed; argv never carries download flags; stub tripwire exits 3 on any; tests assert argv and env (D-09) |
| T-06-07 | Tampering | Option injection through the model path | medium | mitigate | Path must contain no "://", must resolve strictly to an existing regular file, and is passed absolute so it never begins with "-"; list-form argv, no shell |
| T-06-08 | Tampering | Escape processing rewriting the embedded JSON Schema | medium | mitigate | `--no-escape` on llama-completion and llama-tokenize, asserted in the argv test |
| T-06-09 | Denial of service | Runaway generation or hung child | medium | mitigate | Mandatory `-n` cap per stage (ADR 0020), `run_bounded_process` timeout and output caps, process-group kill |
| T-06-10 | Tampering | Oversized prompt silently truncated by the engine | medium | mitigate | Exact `llama-tokenize` count checked with `PromptBudget` before generation; `PromptTooLargeError` names stage and sizes; no truncation or chunking (D-08) |
| T-06-11 | Elevation of privilege | Loopback listener started by llama-cli | medium | mitigate | `llama-completion` only (D-17); `--port` and `--host` are tripwire flags |
| T-06-SC | Tampering | npm/pip/cargo installs | low | accept | No package is installed by this plan |
</threat_model>
