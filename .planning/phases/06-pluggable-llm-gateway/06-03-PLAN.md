Create `src/lecture_study/llm/run_record.py` with the interfaces above (D-13 amended by D-18). Models are strict, extra-forbid and frozen. `RecordingGateway` wraps an inner `LlmGateway` for one declared stage, implements `complete` and `describe`, and keeps only counters: calls (incremented on every request), retry_calls (requests with `is_retry` True) and cumulative call seconds measured with `time.monotonic()` (counted for failed calls too). It never stores the request prompt or the response content. `LlmRunRecorder.track(gateway, stage=...)` returns a new `RecordingGateway` and remembers it.

`record_llm_run(...)` is a `contextlib.contextmanager`: it first validates `lecture_id` with `TypeAdapter(SafeIdentifier)` (a malformed id raises before anything is written, so no path is ever built from an unvalidated id), stamps `started_at` as an aware UTC datetime, yields the recorder, and on exit (success or exception) builds an `LlmRunRecord` with status "succeeded" or "failed", `finished_at`, `wall_seconds`, and one `GatewayUsage` per tracked gateway. `model_sha256` is the SHA-256 hex digest of `describe().model_path` streamed in 1 MiB chunks with `hashlib.sha256` (None when the identity has no model path, or when the file cannot be read, in which case a warning is logged with the path only). It writes atomically: `run_record_path(root, lecture_id, script_stage)` is `root / lecture_id / f"{script_stage.value}.json"`; create the parent directory, write `model_dump_json(indent=2)` to the same name plus ".tmp", then `Path.replace`. An exception from the body is re-raised after the record is written.

Create `tests/llm_gateway/test_run_record.py` with an in-memory gateway whose `describe()` returns a model path pointing at a small tmp file: a successful block with two requests (second `is_retry=True`) writes `ROOT/lec-1/semantic.json` whose top-level keys are exactly {record_version, lecture_id, script_stage, schema_name, status, started_at, finished_at, wall_seconds, gateways}, with calls 2, retry_calls 1 and model_sha256 equal to `hashlib.sha256` of the tmp file; a distinctive prompt marker and response marker never appear in the file text; an exception inside the block writes status "failed" and propagates; a lecture id "../x" raises before any file exists under the root; no ".tmp" file remains and a second run replaces the first; two tracked gateways (critic and drafting) produce two usages; location safety: `LLM_RUNS_ROOT == Path("workspace/data/llm_runs")`, and loading `scripts/generate_progress_dashboard.py` by path shows "llm_runs" is not one of the stage directory names in its `_STAGES` table (the dashboard counts entries of those fixed directories only). | Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
