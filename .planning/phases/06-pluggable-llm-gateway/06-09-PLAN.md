Output: orchestrator changes, the criterion 1 and 2 tests, updated `tests/test_cli.py`, extended layering test.

Design choice (Claude's discretion, D-12): the stage set comes from a new trailing `PhaseSpec` field `llm_stages: tuple[Stage, ...] = ()` set only on the real registry rows 5, 6, 7, 13 and 14. Test registries built from fake specs (for example in `tests/test_personal_study_mode.py`) therefore trigger no preflight, and phase 12 can never be mistaken for stage 18. The preflight covers every LLM stage in the entry point's phase selection, independent of resume predicates, so a misconfiguration fails before any work. Stage 18 is not orchestrated and keeps its own script-level validation (06-07).
