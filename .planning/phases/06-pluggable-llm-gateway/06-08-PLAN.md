<objective>
Migrate stage 14 (whole-lecture podcast script, ADR 0037) onto the gateway following the 06-05 shape (GW-01, D-01). Replace the podcast's retry-after-process-failure with uniform typed call errors without retry (D-22), and expose the per-call timeout override D-03 allows for the large podcast prompt.

Purpose: last of the six LLM-backed scripts; the one with the largest prompt and the special error wrapping.
Output: migrated podcast script and its rewritten tests.

Behavior change made on purpose (recorded in ADR 0046 by 06-11): before this plan a failed `codex exec` was wrapped as a contract error and retried once; after it, a process failure raises `LlmCallError` and is not retried. Timeout default stays 900 s; `--call-timeout-seconds` lets the operator raise it without inventing a new default (RESEARCH assumption A6 left unresolved on purpose).

Execution rules: invoke `clean-code` and `clean-architecture` before writing code (R0.3). Keep the prompt, pt-BR console text, the compiler call and the uncertified marker unchanged.
</objective>
