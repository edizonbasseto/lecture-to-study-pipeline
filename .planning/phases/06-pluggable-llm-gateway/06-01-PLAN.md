## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| pipeline to Codex child process | Prompt text (lecture content) and environment cross into a remote-model CLI |
| Codex child output to pipeline | Model-controlled bytes return through the response file |
| error text to logs | Exception messages and chains reach stderr and persisted failure logs |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01 | Information disclosure | `CodexCliAdapter` error mapping | high | mitigate | LlmCallError reasons carry exit code, timeout, cap and an `llm_output_diagnostic` digest only; raised `from None` so the prompt-bearing argv in CalledProcessError never reaches a traceback; tests assert the prompt marker is absent and the cause is suppressed |
| T-06-02 | Information disclosure | Codex child environment | high | mitigate | Environment is `sanitized_child_process_environment()` plus HOME only; `run_bounded_process` re-applies the credential blocklist; test asserts `OPENAI_API_KEY` and `PORTAL_PASS` never reach the child |
| T-06-03 | Elevation of privilege | Prompt injection in lecture text steering Codex to read local files | high | mitigate | Byte-identical `--sandbox read-only`, scratch directory as cwd and `-C` (the repository root holds `.env`); test asserts the cwd is not the repository root |
| T-06-04 | Denial of service | Oversized argv (E2BIG) and runaway child | medium | mitigate | Argv budget guard raises PromptTooLargeError before spawn; `run_bounded_process` timeout, output caps and process-group kill |
| T-06-05 | Tampering | Parser ambiguity or retry replaying model bytes | medium | mitigate | `complete_json` reuses `parse_llm_json_response` and the 2 KiB `build_bounded_retry_prompt_section`; gateway errors are never retried |
| T-06-SC | Tampering | npm/pip/cargo installs | low | accept | This plan installs no package (RESEARCH Package Legitimacy Audit: none) |
</threat_model>
