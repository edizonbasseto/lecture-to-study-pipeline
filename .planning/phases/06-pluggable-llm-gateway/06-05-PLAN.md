<objective>
Wire configuration, egress policy and adapters into one factory (D-10, D-12, D-14), add the composition helpers that scripts and the CLI share, and migrate the pilot script, stage 5 semantic ledgers, onto the gateway with its run record (GW-01, D-01, D-13/D-18).

Purpose: the tracer of the whole phase: configuration, policy, factory, adapter, complete_json, script and sidecar are proven end to end on the smallest script, the only one whose domain error (traceability) is retried. Later migrations copy this shape.
Output: `llm/factory.py`, `cli/llm_gateway_wiring.py`, migrated semantic script, shared `ScriptedGateway` test double.

Layering (D-02, clean architecture): `llm/factory.py` may import the adapters, config and egress modules of `llm/` but nothing from `study_materials/` or `cli/`. The composition module lives in `cli/` (the composition-root package; `cli/__init__.py` is empty so importing it is light) and is the only place joining `llm/` with the registry-backed policy of `study_materials/`. Scripts depend on `cli.llm_gateway_wiring` and `llm`; `llm` depends on neither.

Execution rules: invoke `clean-code` and `clean-architecture` before writing code (R0.3). Formal en-US for code and errors; existing pt-BR console strings stay. No absolute home paths.
</objective>
