<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser or check client to the site app over local HTTPS | credentials and session cookie cross here |
| generated secrets to the filesystem | demo password, session secret and TLS key are written to disk |
| dry-run fixtures to the guide child process | the guide reads fixture artifacts and writes into tmp roots |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-11 | Information disclosure | demo credentials, session secret, TLS key | high | mitigate | Generated at run time with `secrets` and openssl under workspace/demo/site-access/ (gitignored, plus *.pem and .env ignore rules), files 0o600 and directory 0o700, password only in the .env file, config/site-credentials.txt never written; acceptance runs git check-ignore |
| T-07-12 | Spoofing | signed-in check | medium | mitigate | Real CSRF-protected POST /entrar flow; the check fails unless the anonymous request is refused and the signed-in request succeeds |
| T-07-13 | Tampering | openssl invocation | low | mitigate | Argument list from certificate_command, resolve_trusted_executable, run_bounded_process with timeout |
| T-07-14 | Tampering | generate_site directory reset in the dry run | medium | mitigate | Every root argument in the test points into tmp_path; the test never calls generate_site with defaults |
| T-07-15 | Information disclosure | demo server reachable from the network | medium | mitigate | DEMO_SITE_URL and the serve target (07-06) bind 127.0.0.1 only; certificate covers loopback only and expires in two days |
| T-07-SC | Tampering | npm/pip/cargo installs | low | accept | No package is installed; httpx and python-dotenv are already project dependencies |
</threat_model>
